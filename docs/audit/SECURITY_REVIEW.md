# Security review

## Working-tree update

The externally edited [app.py](../../backend/app.py) removes raw exception JSON and query print statements, but retains global CORS and debug in the script entry point. A nonempty array, nonnumeric top_k and invalid regex still returned 500. Rich routes lack a top_k bound and expose additional profile fields. Health and metadata routes add public surface, including sample usernames. Validate both route families and cap top_k. Debug exposure depends on a startup path that reaches the server. The table below describes the committed baseline.

Scope covers checked-out Flask and React source, configuration, data artifacts and notebook collection code. The threat model assumes a public or shared-network deployment is possible in the future. Current deployment and exposure are unverified. Findings below distinguish runtime observations from conditional impact.

| Finding | Priority / effort | Evidence and impact | Next action and verification |
|---|---|---|---|
| Debug configuration and raw errors | P0 / S | app.py (`128b152:backend/app.py:85`) exposes exception strings in JSON and enables debug when run as a script. Exposing the debug server could disclose internals or expose interactive debugging. | Default to debug off, return a stable generic error schema, use a production WSGI server for deployments and keep redacted diagnostics server-side. Verify invalid requests contain no internals. |
| Malformed request and regex handling | P0 / S | app.py (`128b152:backend/app.py:31`) assumes an object and passes location to regex-enabled `str.contains`. A JSON array and location `` each returned 500 in the test client. Costly patterns can consume CPU. The method allowlist already returns 400 for unsupported values. | Validate object, field types, lengths and accepted domains. Use literal filtering and normalize inputs. Test malformed JSON, wrong content type, arrays, nulls and regex characters. |
| Inference abuse | P0 before exposure / M | [Semantic route (`128b152:backend/app.py:67`) accepts unauthenticated requests, encodes text and scans the whole corpus. No explicit payload, input-length or concurrency limit is configured in the app. | Bound body and text size, define rate and concurrency limits at the service boundary, set worker timeouts, and load-test denial behavior. Choose authenticated access only if the intended audience requires it. |
| Cross-origin use | P1 / S | Global CORS (`128b152:backend/app.py:10`) reflected a synthetic unrelated origin. This lets arbitrary sites read responses when they can reach the service. No cookie or credential flow is implemented. | Prefer same-origin routing or an explicit origin allowlist. Test allowed and blocked preflights and actual requests. CORS does not limit non-browser clients. |
| Identifiable snapshot redistribution | P0 before exposure / M | [Data card](../data_card.md) and [tracked snapshots](../../backend/data/) contain names, usernames, profile URLs, bios, self-reported locations and geocoded coordinates. Serving returns a subset and semantic JSON includes bio even though React does not render it. Scores and embeddings are derived data. | Decide whether publication and redistribution fit the intended educational scope and applicable source terms. Keep minimized serving artifacts or synthetic demo data, redact precise coordinates, document provenance and deletion including derived artifacts. Current Git history already contains snapshots. Obtain separate approval for any history action. |
| Model and package provenance | P1 / M | [requirements.txt](../../requirements.txt) gives lower bounds, app.py (`128b152:backend/app.py:23`) names a model without a revision, and the [frontend lockfile](../../frontend/package-lock.json) pins an older dependency graph. No tracked scan or artifact integrity gate. | Lock the resolved Python environment, pin a model revision and verify artifact checksums. Run npm audit and pip-audit against resolved manifests, then assess browser, tooling and runtime reachability. Advisory applicability is unverified. [Axios advisories](https://github.com/axios/axios/security/advisories) |
| Request logging and credential hygiene | P1 / S | app.py (`128b152:backend/app.py:37`) prints user-entered location and domain. [Collection notebook](../../notebooks/github_analysis.ipynb) shows a token placeholder. A limited source scan found no modern GitHub token-shaped literal in notebook source. | Log status, request IDs and timings without query text. Use environment-based credentials for collection and scan source, saved outputs and history before sharing. |
| External profile links | P2 / S | [App.js](../../frontend/src/App.js#L150) renders dataset URLs in new tabs with `rel="noreferrer"`. The two serving tables had HTTPS GitHub prefixes for all URLs. The raw snapshot includes other values. | Validate parsed URLs at ingest and constrain links to canonical GitHub profile URLs. Test tampered fixture rows. |

The Flask probes used real artifacts and a stub encoder. They established partner error behavior and confirmed that exceptions raised by the encoder are reflected in bio error payloads. Actual model behavior, exploitability under a deployed topology, historical credentials, legal rights and the full CVE inventory remain unverified.
